
# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

## Project Description

This project demonstrates my understanding of Python functions, parameters, return statements, and default parameters.

## Files

- **welcome.py:** Contains a welcome() function that returns greeting messages for different people.
- **toolbox.py:** Contains three functions: double() to multiply a number by 2, is_pass() to check whether a score is 50 or above, and greet() to generate greeting messages.

## Reflection

The hardest function for me to write was greet() because I had to understand how default parameters work. I learned that Python can use a default greeting when another greeting is not provided.
